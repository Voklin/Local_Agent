# Настольная Лола: окно, трэй и чиби-анимации

Пользователь выбрал немедленную реализацию пункта 5. Пункты аудита, субагентов,
JSON-протокола и полной IDE остаются планами в главах 49–52; новые возможности
субагентов/VSIX не объявляются включёнными этой доработкой.

## Использование

Откройте **Настройки → Голос и Лола → Лола на рабочем столе** либо настройки во
вкладке Лолы. Включите спутника, выберите режим и нажмите «Применить расположение
Лолы». По умолчанию спутник выключен, автозапуск Windows не добавляется.

Три режима:

- **Поверх обычных окон** — прозрачный спутник без рамки/кнопки на панели задач.
- **Обычное окно на рабочем столе** — персонаж использует обычный порядок окон.
  Это обычное окно с нормальным z-order, не встраивание в обои/Explorer WorkerW.
- **Только в трее** — окно персонажа скрыто; открыть Neutral и управление можно
  из меню значка. Голосовой сеанс приложения остаётся доступен.

Лолу можно перетаскивать за персонажа. Нажатие открывает/сворачивает облачко:
последний ответ, текстовый вопрос, микрофон, Stop, настройки и переход в Neutral.
Микрофон запускается по явному действию; существующая фраза активации включается
отдельно. Повторное нажатие микрофона завершает запись. Отправка распознанного
текста сохраняет настройку «сразу отправлять»; без неё текст можно проверить
в основном голосовом интерфейсе. Stop прекращает задачу, озвучку, ручную запись
и выключает wake listening.

В трее: открыть Neutral, показать Лолу, запись, Stop, поверх окон, пропуск кликов,
скрытие, настройки, выключение спутника и полный выход. При пропуске всех кликов
восстановление управления выполняется через трэй. Размер — 180–360 пикселей.
Позиция сохраняется в DIP и ограничивается workArea ближайшего монитора; при
исчезновении дисплея окно переносится в доступную область.

Если спутник включён, закрытие основного окна скрывает его в трэй. Проверка
несохранённых изменений редактора остаётся. «Выйти из Neutral» завершает Core,
дочерние операции и трэй. Без включённого спутника прежнее закрытие не меняется.
Безопасный desktop Windows/UAC и специальные режимы других приложений не являются
поверхностью, над которой обещается показ спутника.

## Внешность и анимация

Референс: предоставленная `ebbce888-9e75-4186-9fe4-705cdf0ecfb8.avif`.
Сохранены длинные светлые волосы, боковой пучок, розовато-карие глаза, белая
повязка и чёрно-белый костюм горничной. Персонаж — чиби во весь рост, включая обувь.

Концепт: [lola-chibi-concept-v1.png](../apps/desktop/src/assets/lola-chibi-concept-v1.png).
Рабочий атлас: [lola-chibi-atlas-v1.png](../apps/desktop/src/assets/lola-chibi-atlas-v1.png),
948×1659 RGBA, сетка 4×7, ячейка 237×237. Есть 28 нарисованных кадров, а не только
перемещение одной картинки. Внутрикадровые поля и guard маска защищают от соседних
фрагментов; персонаж уменьшен внутри viewport, чтобы обувь не обрезалась.

| Состояние | Кадры и связь с работой |
| --- | --- |
| idle | Ожидание, дыхание/моргание; blink loop с паузой. |
| listening | Внимательный наклон и жест к уху; реальные recording/wake state. |
| thinking | Взгляд и рука у подбородка; запрос модели, STT или создание голоса. |
| working | Меняются жесты рук; текущая работа инструментов, отдельная подпись при approval. |
| speaking | Открытый/закрытый рот и жесты; статус реального voice playback. |
| success | Взмах рукой/подмигивание после завершения задачи, затем idle. |
| error | Просьба о помощи при ошибке/неподтверждённом действии. |

Это циклическая кадровая 2D-анимация. Фонемный lip sync, скелетный Live2D/3D rig
и произвольные движения не реализованы и не требуются для текущего показа состояний.
Пользователь может отключить анимацию; учитывается системный prefers-reduced-motion.
Тот же новый персонаж используется во вкладке Лолы. Голос Serena не переобучался.

Изображения созданы встроенным imagegen; точные промпты и происхождение находятся
в [lola-chibi.prompt.md](../apps/desktop/src/assets/lola-chibi.prompt.md). Исходный
AVIF пользователя не добавляется в репозиторий. Старый miya-states сохраняется как
исторический материал предыдущих глав; рабочий import использует новый atlas.

Методы DesktopLola: `status` читает snapshot; `configure` валидирует/атомарно
сохраняет и откатывает настройку при ошибке; `present` принимает только визуальные
данные; `persist` использует temporary file/fsync/rename; `menuConfigure` перехватывает
ошибки native menu; `push` отправляет bounded frame; `menu` создаёт Tray actions;
`apply` создаёт/скрывает/удаляет окно/трэй; `applyBounds` учитывает дисплей; `move`
принимает только небольшие конечные deltas; `action` проверяет enum и длину текста;
`dispose` закрывает окно, трэй, timers и IPC handlers. TypeScript AST generator
пока не перечисляет class methods, поэтому их назначение явно приведено здесь.

Main IPC принимает сообщения только от соответствующего mainFrame: отдельный
allowlist для widget и прежний для полного интерфейса. Модель не получает
desktop widget API. Overlay не может подтвердить file diff или вызвать программу.
Ожидающий approval/передача кода отображаются подписью; проверка выполняется в Neutral.

## Один голосовой контур

Core, WakeListener, MicrophoneRecorder и NeuralAudio не запускаются второй раз
в overlay. Основной renderer остаётся владельцем голосового сеанса, в том числе
при скрытии. Widget передаёт пользовательское действие; App переключает нужную
голосовую область, VoicePanel применяет существующие guards и настройки.

Это обеспечивает работу из трея при обычном скрытии. Падение/перезагрузка основного
renderer по-прежнему останавливает голос; отдельный VoiceSessionController/audio
host — будущий шаг архитектуры, не скрытая вторая реализация аудио.
На время desktop/wake фоновые timers основного renderer не throttled. Overlay
сам не загружает LLM, STT, TTS или WebGL; картинка декодируется один раз, анимация
не делает model requests. Точный CPU/RAM зависит от драйвера/дисплея и требует замера;
обещания нулевого расхода ресурсов нет.

## Проверки

[lola-preferences.cjs](../tests/electron/lola-preferences.cjs): opt-in, недопустимые
значения/NaN, размер, отрицательные координаты дисплея, малый экран, bounded frame.
[lola-desktop-smoke.cjs](../tests/electron/lola-desktop-smoke.cjs): настоящий transparent
BrowserWindow/Tray, topmost, закрытие основного окна в трэй, отдельный preload и
отказ чужому sender, изменение кадров, drag, click-through, отключение движения,
режимы desktop/tray, настройка на диске и текстовый ответ при скрытом основном окне.
За сценарий используется один Core и один streaming model request к localhost fixture.
Тестовый HWND почти прозрачен, настоящий микрофон и слышимая озвучка не включаются.

Windows потребовал явно задать уровень z-order после показа окна; рабочий режим
использует pop-up-menu level и workArea, чтобы не размещаться поверх панели задач.
Официальные основания: [BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window),
[Tray](https://www.electronjs.org/docs/latest/api/tray).
