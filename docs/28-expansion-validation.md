# Проверка расширения 6.1

Проверено 23 октября 2026 года. Это журнал приёмки возможностей из
[плана расширения](EXPANSION_PLAN.md), а не обещание совместимости с любой моделью.

## Исходники

| Проверка | Результат и смысл |
| --- | --- |
| `python -m unittest discover -s tests -q` | 106 тестов, успешно; один Windows symlink-тест пропущен окружением |
| `python -m unittest discover -s tests/migration -q` | 69 тестов, успешно: реальные loopback HTTP, stdio Core, JSON write с approval, STT multipart/cancel, две модели и возврат результата Мии |
| `npm run build` | TypeScript renderer/main/preload и production assets собраны |
| Electron GUI smoke | Успешно на новом временном профиле: редактор, diff/conflict, streaming, Stop, настройки, Chat/IDE/Мия, изоляция истории, запись синтетического WAV и редактирование транскрипции, локальный preview снимка |

В GUI fixture микрофон заменён синтетическим Chromium audio device, а
`desktopCapturer.getSources` возвращает изображение 1×1. Это проверяет маршруты
IPC и UI без записи голоса и рабочего стола пользователя. Один холодный запуск
не уложился в прежнее ожидание первого diff 10 секунд; оно увеличено до 30 секунд.
Отдельный повтор не дождался списка моделей. Следующий полный GUI-прогон с
журналом запросов fixture прошёл; тайм-ауты не выдаются за успешные запуски.

Telegram проверен с HTTPX MockTransport: пропуск старых команд, чужих пользователей,
групп и пересылок; отправка только owner, точный approval ID, `/result`, `/resume`,
возврат результата делегирования, отключённый link preview и очистка токена.
Настоящий BotFather token не использовался. Подключение своего бота проверяется
пользователем после ввода токена и user ID в приложении.

## Реальная локальная модель

`Qwen2.5-Coder-7B-Instruct-Q4_K_M.gguf` запускалась включённым CPU llama.cpp
с `K=q8_0`, `V=q8_0`, 3 потоками и контекстом 4096. В режиме JSON без native tools
модель вызвала `read_file`, прочитала тестовый файл и вернула точный маркер
`PROJECT_MARKER_7429`. Время задачи — 71,98 секунды. Собственный процесс сервера
остановлен после проверки; LM Studio пользователя не останавливался.

Реальная модель добавила комментарий после JSON. Парсер принимает объект только
с начала ответа и проверяет имена и аргументы; команды внутри обычного текста
не исполняются. Последующая корректировка примера в системной инструкции выбирает
первый разрешённый инструмент вместо жёстко заданного `read_file`; её проверяет
контракт JSON для Мии с единственным `delegate_task`.

Также проверен настоящий публичный поиск: результат содержит ссылки на Python
documentation. Сетевые результаты зависят от доступности DuckDuckGo и не заменяют
локальные тесты парсера и ограничений доступа.

## Границы проверки

Сервер распознавания речи и STT-модель не включены в установщик: нужен запущенный
whisper.cpp или совместимый transcription API. Физический микрофон и качество
распознавания конкретного голоса не проверялись. Голоса TTS берутся из Windows.

Скриншот показывается локально; изображение не отправляется текстовой модели.
Анализ через VLM, управление мышью и клавиатурой не реализованы. Дополнительные
папки доступны только для чтения по путям из исходного сообщения пользователя.

Параметры KV управляют включённым llama.cpp. Для внешнего LM Studio кеш меняется
в настройках самого сервера. Модели и их веса пользователь выбирает отдельно.

## Готовый Windows-пакет

Финальный замороженный Core прошёл все 15 `test_bridge_process` сценариев.
Production build и NSIS installer 6.1.0 собраны. Packaged smoke дважды запустил
`win-unpacked/LocalAgent.exe` с очищенным PATH и несуществующим внешним Python:
Core, runtime/DLL, file renderer, discovery/probe, сохранение настроек после
перезапуска, каталог Windows-голосов, кнопка микрофона и отсутствие тестового
секрета в настройках/логе проверены. Оба процесса завершились сами с кодом 0.

Перед этим проверка выявила оставшийся основной процесс Electron после выхода
Core. Перенос ожидания из `will-quit` в `before-quit` и обычный `app.quit()` после
cleanup устранили воспроизведение. Отдельный полный GUI-прогон проверил Cancel
как для закрытия окна, так и для `app.quit()`: dirty editor и Core остаются живы.
Диагностическое CDP-соединение тест закрывает до ожидания выхода.

Локальный `LocalAgent-6.1.0-setup-x64.exe`: 164218917 байт,
SHA256 `10bafd8a5b7dcd6062424b7cd1291c6aa83ae1d6f56c7085d803363e1bdcd60f`.
GitHub Actions собирает отдельный артефакт; его checksum публикуется рядом с
установщиком и может отличаться от локального из-за метаданных сборки.

Процесс упаковки и состав зависимостей описаны в
[главе 24](24-full-windows-installer.md). Установка/обновление/удаление на чистой
Windows VM и подпись издателя ещё не проверены. Это предварительная сборка.
