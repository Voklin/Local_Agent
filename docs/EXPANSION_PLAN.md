# План расширения LocalAgent

Запрос пользователя: изолированная Мия, KV-cache, JSON tool calling, STT,
профиль и собственная модель Мии, передача задач основной модели, инструменты ПК
с папками только из запроса, поиск в браузере и удалённый Telegram-контроль.

Каждый этап включает реализацию ядра, интерфейса, проверок и документации.

- [x] 1. Отделить scope/history Мии от Chat; старые разговоры сохранить, дать перенос в нужную область.
- [x] 2. Добавить K/V cache f16/q8_0/q4_0 в собственный GGUF runtime и настройки UI.
- [x] 3. JSON-протокол инструментов без native tools API, с тем же dispatcher/diff/approval.
- [x] 4. Сохраняемый профиль Мии: характер, отдельный endpoint/model, голос и STT.
- [x] 5. Микрофон по явному нажатию, ограниченная запись, STT и редактирование текста до отправки.
- [x] 6. Передача задачи из Мии в Chat/IDE с исходным запросом и видимым результатом.
- [x] 7. Инструменты ПК: screenshot, поиск/открытие браузера, только указанные в запросе папки; разрешения не берутся из ответа модели или веб-страницы.
- [x] 8. Telegram long polling: whitelist user ID, состояние/Stop/задача/подтверждения, без публикации токена.
- [x] 9. Интеграционные проверки, документация функций/модулей и новая сборка; результаты — [глава 28](28-expansion-validation.md).

Модель Мии и основная модель могут быть разными ID на одном сервере либо разными
endpoint. Telegram-токен пользователь вводит в приложении, а не в переписке.
Распознавание использует настраиваемый локальный whisper.cpp или совместимый
transcription API; наличие интерфейса не считается проверкой настоящего микрофона.
