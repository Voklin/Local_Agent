# Neutral 7.0.1: прежний знак и установщик Studio

28 октября 2026. Запрос: адаптировать прежний логотип к обновлённому интерфейсу и собрать установщик.

## Логотип

Возвращён прежний знак N с точкой равновесия. Геометрия адаптирована к небольшому размеру: единый скруглённый контур, графитовая плитка, светлая N и мятная точка. React-компонент наследует цвета темы, поэтому знак сохраняется при выборе другого акцента и светлой темы.

Канонический исходник — [assets/neutral.svg](../assets/neutral.svg). [BrandMark](../apps/desktop/src/BrandMark.tsx) использует ту же геометрию с переменными темы. [Генератор](../tools/generate_brand_icons.py) создаёт PNG 512px и ICO с кадрами 16/24/32/48/64/128/256px. Иконки окна, трея, ярлыка и NSIS используют эти файлы. Прототипы не заменяют действующий интерфейс.

## Упаковка

Версия приложения и обоих package manifest/lock обновлена до 7.0.1, чтобы отличать пакет от прежнего 7.0.0. Стабильный appId и каталоги пользовательских данных сохранены. Установщик собирается локально через существующий NSIS pipeline; публикация не выполняется.

Список requirements-build дополнен точными версиями LM Studio SDK, WebSocket зависимостей, watcher, pathspec и tree-sitter JS/TS из рабочего окружения. Это предотвращает потерю новых возможностей при сборке на отдельной машине. Core собирается PyInstaller под Python 3.12 x64; Qt исключён. В комплект входят Electron, frozen Python Core, CPU llama runtime и bootstrap Visual C++ Runtime. Веса LLM/Serena, приватные настройки и голосовой training corpus в пакет не входят. Настроенные внешние TTS/STT серверы остаются отдельными компонентами.

[Packaged smoke](../tests/electron/packaged-smoke.mjs) адаптирован к новому UI: только IDE/Chat в главном окне, микрофон и каталог голосов — в отдельной Лоле. Тест работает во временном профиле, проверяет повторный запуск, сохранение настроек, миграцию истории и работу bundled Core с очищенными PATH/PYTHONHOME/PYTHONPATH.

## Результаты

Установщик: artifacts/windows/Neutral-7.0.1-setup-x64.exe, **174,160,299 bytes** (166.1 MiB), версия PE 7.0.1.

SHA-256: `35ef3914783a3d78791aa4f11b021f02dbe0ed5fd11d0de147199f7f53207227`.

- Core freeze, typecheck/Vite/Electron build и NSIS прошли.
- 17 subprocess проверок именно frozen Core прошли с урезанным PATH; дополнительный index test подтвердил настоящие JS/TS грамматики и watcher внутри пакета.
- Studio visual прошёл, логотип осмотрен в собранном интерфейсе. Семь PNG frames исходного ICO побайтно совпадают с семью RT_ICON ресурсами Neutral.exe.
- Настоящий packaged smoke прошёл два запуска с сохранением настроек, независимой Лолой и миграцией исходных двух чатов без изменения legacy JSON.
- Первый packaged smoke выявил устаревшее ожидание schema 2; оно обновлено на действующую schema 3. Условия целостности и сохранения двух legacy чатов остались строгими.

Журналы находятся в .test-data/neutral-7.0.1-*.log; машиночитаемый итог — artifacts/windows/Neutral-7.0.1-build-report.json, контрольная сумма — artifacts/windows/SHA256SUMS.txt. Пакет не подписан. Предыдущий установщик 7.0.0 сохранён. Реальная установка поверх пользовательского приложения и чистая VM не входят в локальный smoke.
