# Neutral: проекты, разговоры и хранение

## Проект как пространство

Проект объединяет разговоры Chat, IDE и Лолы общим именем и инструкциями.
Списки трёх режимов остаются раздельными. Папка для IDE необязательна: можно
сначала обсуждать идею и добавить файлы позже. Общие инструкции поступают модели
на каждом запуске. Выбор проекта сам по себе не даёт Chat доступ к файловым
инструментам IDE.

**Личное пространство** имеет пустой `project_id`. Существующие разговоры,
в которых этого поля ещё нет, относятся к нему. Миграция не переписывает всю
историю при запуске. `ProjectStore` сохраняет список отдельно в `projects.json`.

Создание и изменение проекта проверяют имя (1–100 символов), инструкции
(до 6000 символов) и существование выбранной папки. Максимум — 100 проектов.
Повреждённый или слишком большой каталог не заменяется пустым молча.

Переключение блокируется во время задачи. При несохранённых файлах редактора
приложение предлагает завершить сохранение или отказаться от черновиков.
После выбора очищаются текущая задача, поиск и редактор; затем открывается
папка выбранного пространства.

Удаление проекта требует подтверждения и удаляет только запись о пространстве.
Разговоры возвращаются в личное пространство. Файлы на диске не удаляются.

## Действия с разговором

Меню «…» рядом с названием содержит:

- Переименование.
- Закрепление и открепление.
- Архив и возврат из архива.
- Создание независимой копии.
- Повтор последнего запроса в новой ветке: исходный разговор сохраняется,
  новый получает историю до последнего запроса, а запрос подставляется во ввод.
- Экспорт Markdown или JSON через системное окно сохранения.
- Перемещение между проектами.
- Для Chat/Лолы — явное перемещение в другой режим.
- Удаление с отдельным подтверждением.

Поиск находит названия и содержимое пользовательских/ассистентских сообщений
в выбранном пространстве и режиме. Возвращается короткий фрагмент совпадения.
Закреплённые разговоры выше остальных; внутри групп используется время обновления.
Архив имеет свой переключатель. Максимум результата — 300 разговоров,
просматривается до 2000 метаданных. Полнотекстовый поиск не читает произвольные
файлы проекта или другие каталоги.

Копия содержит канонические сообщения, включая завершённые tool calls/results,
но не получает прежний активный checkpoint, pending diff или ID запуска.
Это предотвращает повторное применение старого разрешения к новой ветке.

IDE-чат привязан к корню файлов. Его нельзя перенести в проект с другой
настроенной папкой, иначе прежняя история утверждала бы доступ к другому коду.
Интерфейс возвращает объяснение. Для общей дискуссии можно использовать Chat
или пространство с той же папкой. В личном пространстве прежний IDE-чат виден
после открытия соответствующей папки.

## Файлы данных

Совместимый корень: `%LOCALAPPDATA%/LocalCodingAgent`.

| Путь относительно корня | Данные |
| --- | --- |
| projects.json | Имена, инструкции и выбранные папки пространств |
| connections.json | Публичные именованные профили моделей |
| model-preferences.json | Активные публичные параметры основной модели |
| chats/index.json | Восстанавливаемый индекс метаданных |
| chats/<id>.json | Каноническая история и связанное состояние |
| tasks/<id>.json | Контрольная точка одного запуска |
| extensions/registry.json | Переключатели, MCP-схемы, состав пакетов |
| extensions/skills/user_<uuid>.json | Пользовательские инструкции и черновики |
| extensions/logs/<id>.log | Диагностика локального MCP сервера |

Прежние файлы голоса, заметок, памяти и настроек Лолы остаются по своим путям.
API-ключи профилей и Bearer-токены MCP в эти JSON не записываются. Для Chromium
сохраняется прежний каталог `localagent`, чтобы обновление не потеряло оформление
и зашифрованные данные Telegram. Явно заданный `--user-data-dir` имеет приоритет,
что используется в изолированных тестах.

Markdown-экспорт содержит пользовательские и ассистентские сообщения. JSON
содержит публичные метаданные и канонические сообщения, включая результаты
инструментов; такой файл может содержать данные проекта. Максимальный экспорт —
10 МБ. Экспорт выполняется по явной команде пользователя и выбранному пути.

## Контракты между слоями

Все перечисленные методы проходят прежнюю проверку отправителя в Electron main:
разрешена только основная frame окна приложения. Renderer не получает Node API.
Preload содержит конкретные методы, а не универсальное выполнение произвольного RPC.

| Preload | Bridge | Назначение |
| --- | --- | --- |
| listWorkspaces | workspace_list | Каталог проектов и выбранный ID |
| saveWorkspace | workspace_save | Создать или изменить проект |
| selectWorkspace | workspace_select | Переключить пространство и папку |
| deleteWorkspace | workspace_delete | Удалить группу, сохранить разговоры |
| searchChats | chat_search | Поиск и выбор архива |
| updateChat | chat_update | Pin/archive/project_id |
| deleteChat | chat_delete | Подтверждённое удаление и очистка checkpoint |
| forkChat | chat_fork | Копия или подготовка повторного запроса |
| exportChat | chat_export + save dialog | Экспорт по выбранному пути |
| listConnections/saveConnection/deleteConnection | connections_* | Публичные профили |
| listExtensions/configureExtensions | extensions_* | Реестр возможностей |
| importPlugin | extensions_import + open dialog | Ограниченный JSON-файл |
| discoverMcp | mcp_discover | Асинхронное подключение и список tools |

Мутации истории проверяют `chat_id`, режим, `project_root` и `project_id` вместе.
Обращение к чату чужого пространства отклоняется. Архивирование или перемещение
активного разговора очищает его активный выбор. Задача не может продолжить
сохранение в удалённый разговор: изменение истории запрещено, пока задача работает.

MCP discovery выполняется отдельным потоком bridge, чтобы медленный сервер не
блокировал чтение входящих строк. Model discovery, STT и поиск проекта сохраняют
свои прежние асинхронные пути. Сам AgentEngine выполняется одним task-потоком.

## Проверки

`tests/test_neutral_conversations.py` проверяет изоляцию, перемещение, поиск
сообщений, pin/archive/delete, подтверждение, ветвление без повторного checkpoint
и экспорт. Отдельно проверяется отсутствие API-ключа в профиле.

`tests/electron/neutral-smoke.cjs` использует настоящие preload/main/bridge,
временную папку проекта, локальный модельный HTTP-сервер и MCP fixture. Окно скрыто,
озвучка и пользовательские приложения не запускаются. Проверяются действия через
интерфейс, макет при минимальном размере окна и светлая тема. Снимки сохраняются
в `.test-data/neutral-gui`, тестовые данные не коммитятся.
