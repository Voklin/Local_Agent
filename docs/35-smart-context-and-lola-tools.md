# 35. Умный контекст и повседневные инструменты Лолы

В 6.7 контекст сокращается автоматически, без отдельного запроса к модели.
Лола получила музыку, локальные заметки, таймеры, часы и калькулятор.
Оформление и существующие настройки моделей сохранены.

## Как пользоваться

В режиме Лолы можно попросить: «Посчитай (125*8)+20/4», «Запомни: купить чай»,
«Найди заметки про чай», «Поставь таймер на пять минут», «Какие таймеры активны?».
Локальные утилиты не требуют включения управления ПК. Заметки общие для Лолы
на этом ПК, хранятся в assistant-notes.json каталога APP_DIR вне проекта.
Таймеры работают только пока приложение и ПК работают; после закрытия не
восстанавливаются. По завершении появляется уведомление внутри приложения,
а при разрешённых Windows уведомлениях — системное уведомление.

Для музыки, браузера, скриншотов и открытия приложений включите **Инструменты ПК**
в настройках подключений. Примеры: «Найди музыку для работы в YouTube»,
«Найди песню … в Яндекс Музыке», «Открой найденный трек».
Поддерживаются поисковые страницы YouTube, Яндекс Музыки, VK Музыки и Spotify.
Сервис может требовать аккаунт, доступность в регионе и нажатие Play.
Открытие страницы или системного плеера не означает подтверждённого звучания:
инструменты явно возвращают playback_confirmed=false, и модель не должна
утверждать, что музыка уже играет. Управления аккаунтом, подпиской, громкостью
сервиса и кнопками браузера в этой версии нет.

Для локальной музыки укажите разрешённую папку непосредственно в запросе:
`Открой C:\Music\track.mp3 из папки "C:\Music"`.
Используется системный плеер. Поддерживаются mp3, wav, flac, ogg, m4a, aac,
wma, opus. Папки из ответа модели и найденной страницы доступ не расширяют.
Существующие list_applications/open_application, browser_search, скриншоты и
чтение разрешённых папок сохраняются. Набор прав IDE от этого не расширяется.

## Устройство сжатия

1. ContextManager строит временную копию истории перед каждым запросом модели.
   Каноническая история, checkpoint и содержимое файлов не перезаписываются.
2. agent/smart_context.py включает сжатие при достижении 80% max_context_chars
   либо превышении recent_rounds (обычно 12 полных групп сообщений).
3. Исходный запрос текущей задачи, последний пользовательский запрос и последняя
   группа tools защищены. Аргументы tool calls, в том числе полный код записи,
   не обрезаются. Assistant tool calls остаются вместе с ответами tools.
4. Большие результаты чтения заменяются валидным JSON с путём, статусом,
   ошибкой, исходным размером, SHA-256 fingerprint и релевантными фрагментами.
   Это явно фрагмент, а не полный файл: для точного редактирования требуется
   повторное чтение. Повторяющиеся факты о пути заменяются последним фактом.
5. Старые полные группы переходят в архив данных: явные ограничения пользователя,
   краткие запросы/решения и подтверждения инструментов. Архив имеет роль
   assistant и не повышает найденный текст до system-инструкций или разрешений.
6. Если обязательный код или ограничения не помещаются, выполнение останавливается
   с понятной ошибкой увеличения бюджета, а не отправляет обрезанный код.

Алгоритм evidence-ledger-v1 детерминированный: ранжирует строки по словам запроса,
положению и маркерам ограничений. Дополнительные токены на LLM-суммаризацию не
расходуются. Это эвристическое сокращение, а не гарантия сохранения каждого
смысла; полная история остаётся источником восстановления. Бюджет измеряется в
символах сериализованного JSON, не равен tokenizer/context_length сервера.
Панель задачи показывает размер до и после сжатия. IDE передаёт между ролями
полные материалы текущего этапа; превышение их бюджета не маскируется сводкой.

## Файлы и границы

- agent/smart_context.py — размер, fingerprint, отбор фрагментов, архив и сборка.
- agent/context_manager.py — подключение к runtime, метаданные этапа, last_stats.
- agent/engine.py — общий и fallback путь, статистика task.context, инструкции Лолы.
- core/python/assistant_service.py — whitelist утилит; AST-калькулятор без eval,
  атомарные заметки (200, текст до 4000), 20 daemon-таймеров до суток, shutdown.
- core/python/task_service.py — добавляет утилиты только companion-задачам,
  передаёт события, завершает таймеры при shutdown.
- core/python/desktop_service.py — поиск/ссылки музыки и проверка исходных папок.
- apps/desktop/electron/assistantMedia.ts — повторная проверка URL и realpath
  перед shell.openExternal/openPath: фиксированные HTTPS хосты, без credentials,
  нестандартных портов, UNC, исполняемых расширений и обхода через junction.
- apps/desktop/src/App.tsx — ограниченная очередь уведомлений с закрытием;
  TaskProgress.tsx показывает статистику; CompanionSettings.tsx содержит примеры.

Токены сервисов и произвольный shell для новых инструментов не нужны.
Повреждённое хранилище заметок не перезаписывается. При завершении приложения
все таймеры отменяются; таймер не является планировщиком задач Windows.

Заметки поддерживают все 200 записей по 4000 символов, включая русский текст.
Ограничение JSON-хранилища — 6 000 000 байт с запасом на Unicode и JSON-экранирование;
чтение ограничено на потоке. Перед атомарной записью проверяется сериализованный
размер: отказ не меняет прежний файл. Пробелы входят в лимит текста заметки.

## Проверки

Шесть тестов tests/test_smart_context.py проверяют сохранение ограничений,
неизменность истории, пары tools, полный код, корректный JSON, отсутствие новых
system-разрешений и дедупликацию фактов. Шесть tests/test_assistant_service.py
проверяют арифметические ограничения, заметки, однократный таймер, музыкальные
ссылки, кодирование поиска и папки локального аудио. Отдельная host-проверка
tests/electron/assistant-media.cjs проверяет спуфинг хостов, credentials/порты,
расширения и выход через junction без открытия пользовательских приложений.

Общий Python suite: 121 тест, OK (один штатно пропущен); migration/Core: 90, OK.
Наличие тестов не гарантирует доступность сторонних музыкальных сервисов.
