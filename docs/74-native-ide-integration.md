# Native IDE: панель агента и вход в редактор

Обновлено 2 ноября 2026 года. Изменения находятся в рабочей копии и локальном runtime; установщик этого изменения не собирался.

## Пользовательский сценарий

Кнопка «Открыть IDE» в главном окне запускает отдельную Neutral IDE. Выбирать папку заранее больше не требуется. Если в Neutral уже выбрана существующая папка, редактор открывает её; иначе запускается пустое окно. Отсутствующая папка не заменяется текущим каталогом приложения.

В пустой IDE доступны штатные редактор, терминал и расширения. Панель Neutral предлагает «Открыть папку» и «Недавние проекты», вызывающие встроенные действия Code-OSS. До открытия папки сессия агента не создаётся и доступ к произвольным файлам не предоставляется. При открытии папки Extension Host запускает панель для её корня.

## Иерархия панели

1. Строка проекта: имя папки, контекст/инструкции проекта и настройки агента.
2. Текущий разговор: заголовок задачи, история, действия модели и новая задача.
3. Переписка занимает оставшееся пространство. История и подробности открываются отдельно и закрываются прежними кнопками/Esc.
4. Внизу — сворачиваемые план и проверки, поле задачи, выбор модели и отправка/остановка.

Встроенная панель не повторяет шапку настольного приложения, переключатель режимов и его статусную строку. Файлы, вкладки редактора, терминал и расширения принадлежат оболочке Code-OSS. Лола не связана с IDE и не добавлена в её панель.

## Реализация и границы

- `apps/desktop/electron/neutralIde.ts`: запускает собственный runtime с необязательным корнем. Для существующего корня создаёт scoped Core session; без корня только подготавливает соединение.
- `prototypes/neutral-ide/extension/agent-view.cjs`: показывает безопасный стартовый экран без проекта; с папкой загружает React webview. Команды стартового экрана ограничены открытием папки и списком недавнего.
- `apps/desktop/src/App.tsx`: основной вход не вызывает диалог выбора папки; native-host ветка формирует иерархию панели.
- `apps/desktop/src/style.css`: адаптивная ширина и высота панели, включая переопределение минимальной ширины старого Studio layout.
- Существующий Core остаётся единственным исполнителем задач. Применение файлов делегируется редактору с проверкой снимка и подтверждением; грязные буферы блокируют запуск. Работа с несохранёнными буферами не расширена этим изменением.

- `neutral-ide-smoke.cjs`: пустое окно без проекта, отсутствие выбора корня, затем открытие проекта; проверены видимое окно, авторизация bridge и ограничения.
- `neutral-ide-integration.cjs`: реальный Code-OSS/webview/Core, 5 запросов синтетического HTTP-провайдера, подтверждение diff, запись и Ctrl+Z; проверки геометрии всех кнопок верхней панели при ширине 300 px.

## Сценарии Agent / Ask / Plan, правки и дополнения

Рабочий корень берётся из `vscode.workspace.workspaceFolders`, а не из выбранного проекта главного окна. При замене/удалении корневой папки соединение закрывается и панель перезагружается для новой папки. В multi-root workspace используется первая папка: автоматического переключения прав доступа при переходе между файлами нет.

- **Agent** — обычная задача с подтверждением действий.
- **Ask** — исследование с `read_only=true` и отключёнными автоматическими проверками.
- **Plan** — то же ограничение чтения плюс запрос плана: этапы, файлы и проверки. Режим не запускает реализацию автоматически.
- **+ Контекст** — добавляет путь активного сохранённого файла и диапазон строк. До восьми ссылок, каждую можно убрать. Текст буфера не вклеивается в запрос: агент читает файл штатными инструментами с прежними ограничениями.
- **Изменения и проверки** — открывает существующий обзор задачи, результатов и восстановления.
- **Ctrl+Alt+K** или контекстное меню редактора — инструкция по выделению, затем черновик запроса в панели с привязанными строками. Пользователь отправляет его и подтверждает diff обычным способом. Это правка через агента, а не отдельный генератор неподтверждённых замен.
- **Alt+\** — запрос inline-подсказки; **Tab** принимает её в буфер, **Esc** скрывает. Настройка `neutral.completion.automatic` включает автоматические запросы. По умолчанию они выключены, чтобы не нагружать локальную модель на каждое действие.

### Контракт дополнений

`core/python/ide_completion.py` принимает максимум 6000 символов перед курсором и 2000 после; ответ ограничен 160 токенами. Только локальный API, без инструментов и записи файлов. Внешний API отклоняется до создания HTTP-клиента. Используется общий `ModelClient` с планировщиком inference, без загрузки второй модели. Один фоновый запрос, таймаут 30 секунд; новые запросы во время работы отклоняются. Extension Host проверяет версию документа и отмену перед показом подсказки; принятие остаётся штатной операцией редактора. Отмена UI отбрасывает результат, но уже отправленный HTTP-запрос может закончиться в пределах таймаута.

`ide:complete` не предоставляет доступа к shell или произвольному RPC. Путь проверяется относительно scoped IDE root, `.git` исключён. Настройка модели берётся из текущей конфигурации Neutral. Для качественных быстрых подсказок нужна модель, хорошо дополняющая код; с реальной пользовательской моделью качество и задержка отдельно не измерялись.

### Проверки дополнения

Добавлены unit-проверки: внешний API не получает запрос, выход за корень и чрезмерный контекст отклоняются, нет tools, клиент закрывается. Electron-сценарий проверяет контекст активного файла, read-only параметры Ask/Plan, реальный вызов inline provider через Alt+\ и синтетический HTTP-ответ. Эти тесты проверяют интеграцию, а не качество генерации модели.

### Следующие возможности и границы сходства с Cursor

Ориентиры: [режимы](https://docs.cursor.com/en/agent/modes), [обзор изменений](https://docs.cursor.com/en/agent/review). Это собственная реализация Neutral, не перенос закрытого кода Cursor.

Дальнейшие этапы: отдельный inline diff для выделения без перехода в панель; принятие/отклонение отдельных фрагментов нескольких файлов; поиск контекста через @; измерение задержки дополнений и кэширование; явное управление несколькими корнями. Не реализованы эквиваленты Cursor Tab с предсказанием следующей правки, облачных агентов и полного набора интеграций Cursor.

Финальный прогон: 13 целевых unit-тестов, 9 тестов bridge, 3 HTTP-теста IDE-сессий прошли. Реальный Electron/Code-OSS сценарий прошёл с 6 синтетическими запросами, включая Tab → сохранение принятой подсказки и Ctrl+Alt+K → инструкция с контекстом в панели. Ctrl+K заменён на Ctrl+Alt+K из-за конфликта со штатными chord-сочетаниями редактора. Сборка TypeScript/renderer/Electron и `git diff --check` успешны. Проверки не выполняли запросов пользовательской LM Studio модели.
