# Этап 12: создаваемые профили субагентов

28 октября 2026. Этап завершён в границах [roadmap](57-roadmap-v2.md): readonly профили, без writer children/worktrees.

## Как пользоваться

Откройте «Настройки → Расширения → Субагенты». Создайте профиль, задайте назначение и инструкцию, выберите инструменты чтения и включите профиль. В задаче IDE можно указать название или ID профиля; основная модель передаст самостоятельное исследование через delegate_readonly с profile_id. Короткие задачи решаются без делегирования. Общий переключатель полностью убирает оба subagent tools из следующих запросов; одиночный агент продолжает работать.

Модель может вызвать create_subagent_profile. Это только новый **выключенный черновик**: редактировать существующий профиль, включать его или назначать другую модель через этот инструмент нельзя. Пользователь просматривает инструкцию и включает профиль. Удаление профиля не удаляет выполненные исследования.

## Архитектура и права

[SubagentProfiles](../agent/subagent_profiles.py) хранит ограниченный каталог schema 1 в extensions/subagents.json профиля приложения. Atomic replace, RLock, строгая форма, до 50 профилей, ограниченная инструкция; повреждённый каталог не включает встроенные права молча. При первом запуске встроен «Исследователь». SQLite schema 3 не меняется.

[ChildExecutor](../agent/child_executor.py) использует существующие AgentEngine, ToolExecutor, CallJournal, RunRegistry и Scheduler. Нового исполнительного контура нет. Права — пересечение разрешённых definitions родителя и tools профиля. Только list_files/read_file/read_range: инструкции не добавляют файлов, программ, MCP, записи или вложенных детей. Перед началом проверяется текущее включение профиля. Полный снимок профиля и версии сохранён в child checkpoint, название видно в дереве. Последующее редактирование не переписывает историю.

Подключение и модель наследуются от родителя; depth 1, до трёх детей на run epoch, общий inference lease. Ограниченный handback с SHA источников, проверкой доступа и свежести остаётся прежним. Stop/restart не повторяют автоматически ни child generation, ни неизвестные эффекты. Подтверждение внешнего API и политика папок сохраняются; никаких новых API получателей профиль не задаёт.

[ExtensionService](../core/python/extension_service.py) предоставляет CRUD через существующий fixed IPC extensions_configure; host принимает пользовательские изменения только в idle. [TaskExecution](../core/python/task_execution.py) добавляет tools и краткий каталог только IDE с разрешённым чтением. [SubagentSettings](../apps/desktop/src/SubagentSettings.tsx) содержит редактор, включение и подтверждение удаления. Стиль прежний.

## Границы и откат

Это профили исследователей, а не автономные writer workers. Другие модели, Git worktrees и одновременные записи не заявлены. Дополнительный настоящий tool-dispatch test проверяет создание моделью выключенного черновика (входит в финальные 40 связанных tests). Самостоятельный выбор профиля реальной LLM ещё не измерен; HTTP fixture доказывает исполнение и права, не интеллектуальное качество выбора.

Перед откатом сохраните профиль приложения. Старый Core не использует новый каталог; выключенные черновики и история остаются на диске. Существующие данные и docs.zip сохранены. Установщик не собирался.

По просьбе пользователя основной roadmap теперь отложен: следующий рабочий приоритет — измерение и улучшение качества ответов, не этап 16.
