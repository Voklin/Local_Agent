# LocalAgent: подробное руководство по проекту

Документация сопровождает рабочую ветку LocalAgent: базовая версия с потоковыми ответами — коммит `1482424` от 22 октября 2026 года; последующие изменения истории и контекста описаны в главе 4 и рабочем плане. Это учебное руководство и справочник разработчика. Последующие изменения должны обновлять соответствующие главы вместе с кодом.

## Как читать

Если вы только начинаете программировать, идите по главам 1–4, затем разберите один запрос в главе 5. После этого откройте соответствующие файлы в справочнике. Не нужно сразу читать весь `AgentEngine.run`: сначала поймите, кто его вызывает и какие данные он получает.

Если нужно изменить конкретную возможность, начните с карты файлов и главы 12. Для протокола между интерфейсом и Python используйте главу 8; для проблем с записью файлов — главу 9.

## Как соотносятся руководство и справочник

Главы объясняют причины решений, взаимодействия и ограничения. Справочник отвечает на вопрос «где это объявлено и что делает». Его структурная часть извлекается из AST — синтаксического дерева исходников. Описания назначения написаны отдельно и проверяются при генерации; AST сам не способен объяснить намерения разработчика.

Анонимные обработчики JSX и короткие `lambda` не получают выдуманных имён: их роль описана в главах и в окружающих именованных функциях. Внешние библиотеки не включаются в каталог нашего API; для них приведены официальные источники.

## Три разных уровня готовности

Во всём руководстве различаются:

1. **Рабочий путь Electron** — `run-desktop.bat` → Electron/React → Python Core → сервер модели.
2. **Сохранённый путь Qt** — `run.bat` или `main.py` → PySide6 → `AgentWorker` → тот же движок. Поведение интерфейса и хранения настроек у него отличается.
3. **Заготовки и эталон** — MCP-реестр, отдельные примитивы планировщика, менеджер GGUF и большой файл дизайна существуют в репозитории, но наличие класса не означает наличие соответствующей кнопки в Electron.

## Обновление справочника

После установки npm-зависимостей выполните из корня репозитория:

```powershell
python tools/generate_code_reference.py
python tools/check_docs.py
```

Ручные главы остаются источником объяснений. Структурный справочник следует пересоздавать, когда изменяются объявления или расположение строк. Правила сопровождения находятся в [главе 12](12-development-guide.md).

План задачи, этапы, журнал инструментов и результаты разбираются в [главе 15](15-task-progress.md).
