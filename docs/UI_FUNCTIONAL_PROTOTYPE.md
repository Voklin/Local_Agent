# Функциональный прототип Neutral

Дата: 28 октября 2026. Статус: реализация в отдельном прототипе; интеграция нового интерфейса в основной checkout ожидает одобрения.

## Реализация

В `prototypes/neutral-studio` добавлен функциональный renderer на React/TypeScript, который использует копию существующих компонентов и настоящие Electron IPC / Python Core. `build-functional.cjs` копирует исходники в игнорируемую рабочую папку, применяет только изменения UI и собирает renderer; `functional-main.cjs` открывает его с отдельными userData, LOCALAPPDATA и APPDATA. Основные компоненты и Python backend не изменены.

Таким образом, пропуски раннего статического макета закрыты существующими рабочими реализациями: проекты/чаты, редактор, поиск/индекс, память, задачи, фоновая работа, подтверждения и recovery, снимки/откат, настройки и расширения, основной режим и настольная Лола. Подключение каждого внешнего сервиса по-прежнему требует подходящего окружения и пользовательской конфигурации.

Новые UI-части: выбор модели под полем ввода, журнал реальных инструментов в переписке, подробности в скрываемой панели, полный экран настроек, изменяемая ширина панелей, безопасное ограниченное Markdown-подмножество и копирование сообщений. Пользовательский запрос показывается единым блоком с подписью «Вы», тонкой левой границей и переносом длинного текста; удалены два наложенных уровня пузырей. Обычный текст, списки, код и таблицы выводятся без raw HTML.

В IDE недавние разговоры перенесены из левой навигации в раскрываемую панель «Разговоры» в заголовке чата агента, по принципу подробностей задачи. Слева остаются проект, файлы, поиск и память. История использует существующий компонент со всеми действиями, без второго переключателя проекта. Открытие выбранного разговора возвращает к переписке; ширина следует ширине панели агента. Ctrl+K открывает историю и фокусирует поиск, Escape закрывает её с возвратом фокуса. В Chat расположение истории сохранено.

Новый знак Neutral — две равные горизонтали внутри общего круга: равновесие и нейтральная точка. Вектор используется в шапке и настройках; PNG — как иконка окна отдельного прототипа. Установочный пакет и его значки пока не пересобирались.

## Остаточные ограничения

- Отдельный backend делает операции с выбранной реальной папкой реальными; использовать следует с осознанно выбранным проектом. Существующие проверки/подтверждения сохранены.
- Полные аппаратные сценарии микрофона, STT/TTS, wake phrase, внешний Telegram, пользовательские MCP и доступность Docker/LSP требуют конфигурации и отдельной приёмки на машине пользователя.
- Это не перенос компонентов в основное приложение. Окончательная визуальная полировка всех живых состояний, расширенная семантика Markdown и полноценные именованные раскладки остаются отдельными задачами приёмки.

## Запуск

`npm start` из `prototypes/neutral-studio` запускает функциональный вариант; `npm run build:functional` пересобирает его. Основная модель и история в этом профиле изначально пусты. Старый локальный макет остаётся доступен через `npm run design-study`.
