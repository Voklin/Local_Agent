# Текущее состояние LESHY

Актуализировано 3 ноября 2026. Этот документ описывает текущие исходники 7.0.1. Названия Neutral и LocalAgent сохраняются в технических идентификаторах, путях профиля и исторических главах; смена отображаемого бренда не является миграцией данных.

## Основной рабочий путь

Electron/React → JSON-lines Python Core → настроенный провайдер модели. Chat, IDE и голосовая Лола имеют раздельные области разговоров. Для IDE нужен открытый workspace; доступные инструменты определяются режимом, профилем и разрешениями.

Новая IDE использует закреплённый Code-OSS runtime и независимую панель `apps/desktop/src/idePanel`. Главный desktop и IDE обращаются к общему Core через отдельные scoped views. Запись из native IDE выполняет редактор; Python writer не является запасным обходом editor guards. Прежний Studio UI остаётся в исходниках и legacy fixtures. Архитектура и историческая интеграционная проверка — [глава 75](75-ide-panel-rebuild.md).

## Реализованные возможности

| Область | Текущее состояние |
|---|---|
| Модель | OpenAI-compatible Chat Completions, Responses adapter, native/строгий JSON tool protocol; настройки подключения и локального runtime. Наличие адаптера не означает текущую проверку каждого внешнего провайдера. |
| Файлы и команды | Чтение, поиск, range/patch/mutations и подтверждаемые `run_project_command`. Diff approval, source revision и access policy действуют до эффекта. |
| Контекст | Инкрементальный индекс Python/JS/TS, поиск символов, ContextPack с источниками, RequestBudget и автоматический профиль локального контекста. |
| Запуски | RunRegistry, очередь тяжёлой генерации, учёт HTTP attempts/usage, фоновые чаты и TaskGraph. Ожидание approval не должно занимать generation lease. |
| Данные | Версионированное SQLite/WAL-хранилище, миграция прежних JSON, checkpoints, call journal и snapshots. Индекс — восстановимый кэш. |
| Проверки | В новой IDE можно настроить критерии, команды и LSP diagnostics, выполнить проверки без модели. Evidence связан с check_id, областью и source witnesses; exit 0 не доказывает все требования и не сохраняет актуальность после изменения исходников. |
| Расширения | MCP, навыки и профили readonly субагентов. Дочерние исполнители не получают запись файлов/команды через narrative результата. |
| Интерфейс | LESHY: лесная, светлая и сумеречная темы; отдельная IDE-панель, история, approvals и фактическая activity. |
| Лола | Отдельные модель/история, opt-in настольное окно, TTS, STT и голосовые настройки. Аппаратные и модельные свойства требуют отдельных измерений. |

## Границы надёжности

Инструмент с начавшимся, но неподтверждённым эффектом требует явной проверки. Restart и resume не должны автоматически повторять действие. Повреждённый journal и неизвестный rollback могут блокировать запуск; универсальное автоматическое восстановление не реализовано.

Несохранённые editor buffers защищены dirty guard и не являются overlay индексатора. В новой IDE пока нет всех расширенных редакторов плана, правил и MCP; часть настроек доступна через главный desktop. Команды исполняются с полномочиями пользовательского процесса, а не внутри обязательной OS sandbox.

API-ключи и их хранение зависят от используемого пути: ключ основного Electron Core остаётся в памяти, профили подключений и исторический Qt имеют свои контракты. Не следует переносить гарантию одного пути на другой. См. [данные и разрешения](09-data-and-security.md) и актуальные сервисы.

Сохранённый Qt GUI — отдельный совместимый путь; он не имеет подтверждённого паритета с новой IDE. Отсутствие PySide6 приводит к пропуску соответствующего теста.

## Проверенное состояние и поставка

В [аудите 3 ноября](81-project-audit-2026-11-03.md) зафиксированы production build, 494 unit-теста (3 пропуска) и 129 Core/migration-тестов. Это результаты development checkout с локальными HTTP fixtures. Историческая [оценка реальной модели](AGENT_READINESS_RESULTS.md) относится к своему снимку и не является текущей статистикой надёжности.

[Актуальный installer с настройкой проверок](86-ide-acceptance-checks.md) собран 3 ноября; packaged IDE с approval/write/Undo, выполнением checks_only через bundled Node и повторный запуск прошли локальную приёмку. Текущие unit — 496 (3 skips), Core/migration — 129, Node regressions — 27; native/JSON acceptance fixtures и матрица ширин/тем прошли. Эти результаты не заменяют установку/обновление на чистой Windows и remote CI. [Первая волна](84-development-wave-one.md), [recovery](85-recovery-and-session-state.md) и [исходная приёмка](82-leshy-release-acceptance.md) сохраняют свои снимки.

[Измеренный baseline](83-agent-quality-baseline.md): по три повтора Ornith/native и Qwen 2.5 Coder/JSON, затем отдельный JSON auto follow-up. На небольшом manual fixture Ornith прошла bugfix 3/3; multifile не прошёл E2E. Qwen/manual остановилась на бюджете, auto снял эту остановку, но не исправил качество. Разные модели и маленькая выборка не позволяют приписать разницу протоколу.
