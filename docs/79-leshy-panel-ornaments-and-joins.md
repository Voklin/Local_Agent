# LESHY: панель агента, орнаменты и стыки

2026-11-03. Продолжение [проверки окон](78-leshy-all-windows-review.md).

Следующая итерация: [живописные ассеты и полный охват семейств элементов](80-leshy-painted-assets-and-motif-coverage.md). Она заменяет описанные ниже схематичные иллюстрации новыми прозрачными WebP.

## Исправления панели IDE

Нативный Code-OSS добавлял webview `body { padding: 0 20px }`. При viewport 300 px React-панель получала только 260 px. Тест, сужавший один `.nw`, не проверял этот внешний отступ. В независимом entrypoint теперь явно сбрасываются padding и margin html/body/root. Полезная ширина совпадает с реальной шириной webview.

Длинное имя модели также вытесняло шеврон за границу кнопки. Текст вынесен в отдельный сжимаемый span с многоточием и полным названием в title; шеврон сохраняет ширину. Навигация использует три равных столбца, действия composer — сжимаемый столбец режима и две кнопки. Заголовки, прокручиваемая область и composer используют общий отступ. В узкой панели стартовая карточка компактнее; вертикальная прокрутка сохраняет доступ к содержимому.

Убрана лишняя граница между внутренним заголовком и вкладками. Нативная декоративная лента помещается внутри строки заголовка. Уголок над кнопками редактора удалён. Подтверждение правки имеет собственный отступ от края и переносимые кнопки.

Отдельно проверен containing block нативного орнамента: без `position:relative` на title абсолютная лента привязывалась ко всей auxiliarybar и оказывалась у её нижней границы. Геометрический тест сначала получил y774–778 при заголовке y35–70, после исправления — y66–70, внутри заголовка. В SVG окна без проекта также явно задано заполнение currentColor, чтобы части рисунка не оставались чёрными.

## Орнаменты и рисунки

Пользовательские референсы сохранены в `docs/leshy-brief/ornaments-2026-11-03/`. Орнаменты перерисованы геометрически: ромб с диагональными отростками, пересекающаяся лента, угловое плетение и вторичная восьмилучевая розетка. Исходные фото не используются как фоны интерфейса.

React и CSS теперь загружают одни SVG-мастера через маски; копии path в React удалены. Native chrome получает те же файлы через prepare.py. Цвет берётся из семантической палитры темы.

Добавлены четыре локальных SVG-вставки: берёзы, папоротник, грибы, книги с веткой. Они размещены в заголовках настроек, проекта и памяти, в пустой истории, ходе работы и окне IDE без проекта. Иллюстрации декоративные, скрыты от screen reader и не принимают указатель. В обычных формах под рисунок выделено место; при малой ширине рисунок заголовка скрывается. Настройка выключения иллюстраций соблюдается в React-окнах.

Проверка выявила старое `padding:0!important`, отменявшее место под рисунок настроек: при ширине окна около 1102 px и колонке разделов 340 px текст пересекал область рисунка. Удалён приоритет старого сброса. Проверка реальных текстовых прямоугольников теперь даёт `overlap: false`.

## Проверка

| Сценарий | Результат |
| --- | --- |
| `npm run build` | TypeScript и сборка прошли |
| `LESHY_PANEL_AUDIT=1` + `neutral-ide-integration.cjs` | 39 состояний: три темы, настоящие ширины 240/320/420 px, диалог/история/работа/настройки; три ширины подтверждения правки. Длинная модель, 2 fixture-запроса, файл не применялся |
| Обычный `neutral-ide-integration.cjs` | Настоящие Core/Code-OSS, read/write approval, diff, undo, completion, история, настройки; 6 fixture-запросов |
| `NEUTRAL_TEST_EMPTY_IDE=1` | Кнопки и SVG внутри viewport, заполнения рисунка используют цвет темы, 0 запросов |
| `LESHY_WINDOWS_MATRIX=1` + `leshy-themes.cjs` | Восемь разделов настроек, четыре вкладки инструментов, проект в трёх темах; масштаб 125/200%, скрытие рисунков, отсутствие наложения текста |
| `LCA_STAGE16_ONLY=1 LESHY_WINDOWS_MATRIX=1` + `studio-smoke.cjs` | Вложенные редакторы и память в трёх темах; 3 fixture-запроса |
| `lola-desktop-smoke.cjs` | Прозрачность и темы отдельного окна, один Core |

Для запуска через PowerShell задавайте переменные окружения только соответствующему сценарию. Все сценарии используют изолированные профили и HTTP fixture; большая модель не загружалась. Тесты ширины перетаскивают настоящий sash Code-OSS через CDP, а не изменяют ширину внутреннего div. Геометрия учитывает небольшое округление Windows/DPI.

Просмотрены итоговые снимки, включая узкое подтверждение, длинную модель, пустые страницы, рисунки в заголовках, composer и переключатели тем. Выполнено независимое ревью изменённых файлов; замечания о приоритете отступа и размере разделителя исправлены. Полная сертификация доступности, все сторонние webview и новый установщик не проверялись.
