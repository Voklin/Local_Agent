# Новая панель IDE с нуля

2 ноября 2026. Пользователь потребовал отказаться от прежней панели и её UI-наработок.

## Граница переработки

Новая точка входа `src/idePanel/entry.tsx` монтирует `AgentWorkspace` напрямую. Она не импортирует App, StudioControls, useTaskSession, ChatText, ApprovalDialog, старые стили или другие компоненты прежней панели. `workspace.tsx` реализует собственное состояние и обработку событий; `workspace.css` содержит отдельный набор стилей `nw-*`, использующий цвета текущей темы Code-OSS. Старые native-IDE CSS удалены из общего style.css. Главный Chat и Лола остаются в своём приложении.

Сохранён транспорт `ideEntry.ts` → `createApi` → Extension Host → scoped Core. Это протокол связи, а не основа интерфейса. Проверки правок, файлов, отмены и API остаются в существующем ядре.

## Новая структура

- Лаконичная шапка рабочей папки: новая задача и подключение модели.
- Три постоянных раздела: Диалог, История, Работа. Они не накрывают друг друга боковыми выдвижными панелями.
- Пустое состояние с тремя действиями и отдельной типографикой.
- Поле запроса с контекстными ссылками, Agent/Ask/Plan, остановкой и отдельной строкой модели.
- История с поиском и загрузкой чата из текущей папки.
- Работа: изменённые файлы, события инструментов, проверки, диагностический снимок задачи.
- Отдельная форма подключения API и модели.
- Подтверждение действия занимает панель целиком: diff, отклонение, остановка, применение. Tab удерживает фокус в подтверждении.

## События и ограничения

События принимаются только для выбранных chat_id/run_id; event_seq предотвращает повторную обработку. run_id задаётся до startTask, чтобы принять ранние события. task_end снимает состояние выполнения. Ctrl+Alt+K приносит инструкцию и ссылку на выделение через транспортное событие, не импортируя прежние UI-компоненты. Автодополнение редактора не зависит от React-панели.

Расширенные редакторы плана, правил и MCP из прежнего UI не скопированы в новую панель. Настройки расширений остаются в главном приложении. Прерванные вызовы инструментов можно разрешить через новые карточки с отдельным подтверждением наблюдения. Для повреждённого журнала и неизвестного результата отката запуск остаётся заблокирован; универсальное исправление таких состояний не реализовано. Это ограничение новой версии, не подтверждение полного функционального паритета.

## Проверка

Production build прошёл. Сквозной сценарий в настоящем Code-OSS прошёл: отправка задачи, поток ответа, подтверждение diff, запись и Ctrl+Z, read-only параметры Ask/Plan, автодополнение через HTTP и принятие Tab, Ctrl+Alt+K, новая история и форма подключения. Всего 6 синтетических запросов модели; пользовательская LM Studio не нагружалась. Проверяется отсутствие старых `.app-shell/.studio-shell/.composer/.agent-panel` в DOM новой панели. Скриншоты диалога, подтверждения, истории и настроек находятся в `.test-data/stage19`; диалог и настройки просмотрены визуально. Установщик не собирался.

## Доводка новой реализации

- История: переименование, отдельное подтверждение удаления, очистка состояния удалённого текущего разговора. Удаление не отменяет записанные файлы проекта.
- Конфигурация: сохранённое подключение отделено от редактируемого. Пока изменения не сохранены, подпись модели и запуск используют прежнюю конфигурацию. Пустое поле ключа не затирает текущий ключ.
- `runActivity.tsx`: самостоятельный компонент карточек этапов, инструментов, субагентов, файлов и проверок. Типы берутся из общего протокола, старый TaskProgress не используется.
- Неизвестный результат инструмента: пользователь сначала выбирает наблюдение, затем подтверждает его. В Core уходят точные chat_id, journal_id, message_index и call_id. Действие не воспроизводится заново.
- Ошибка разрешения действия отображается внутри панели подтверждения, а не за ней.

Повторный сквозной Electron/Code-OSS тест прошёл после этих изменений. Дополнительно проверены несохранённая модель, переименование в Core, отсутствие удаления до подтверждения, удаление тестового чата и неизменность его файлов. Ресурсы локальной IDE обновлены; пользовательские окна не закрывались. Для загрузки новой версии нужны перезапуск Neutral и IDE. Установщик и публикация не выполнялись.
