# LESHY: живописные ассеты и оформление всех семейств элементов

2026-11-03. Продолжение [проверки панели и стыков](79-leshy-panel-ornaments-and-joins.md).

## Граница IDE/Chat

У `.mode-tabs` убран унаследованный внутренний отступ. Активная вкладка замыкается на рабочую область своим фоном, без нижней рамки и промежуточной полосы. Измеренный зазор уменьшился с 3,8 px до округления −0,2 px. Проверены обе вкладки.

При финальном просмотре найдено переполнение нижней строки: общий минимум высоты кнопок 30 px превышал высоту statusbar 26 px. Автопрокрутка контейнера смещала верхнюю панель на −2,4 px. Кнопка журнала теперь имеет отдельную компактную высоту 22 px. Регрессия сначала воспроизведена тестом, после исправления `topbar.top = 0`, `scrollTop = 0`, кнопка внутри строки. Измерения: `.test-data/leshy-themes/mode-tab-join.json`.

## Четыре новые иллюстрации

Встроенный imagegen сгенерировал грибы, берёзовую рощицу, папоротник и книги по референсам действующих `forest.webp` и `undergrowth-cutout.webp`. Используются подробный тушевой рисунок, гуашь, мох, приглушённые охристые и зелёные цвета, настоящий прозрачный фон. Это полноцветные WebP, а не одноцветные маски. Размер каждого 960×480, общий вес менее 1 MB. Исходные имена генераций и SHA-256 записаны в `apps/desktop/src/assets/leshy/painted-spots.json`.

Все ссылки на прежние четыре схематичных SVG в продукте заменены. Старые рисунки сохранены только в `docs/leshy-brief/retired-schematic-spots/`. Подключены главный экран и боковые зоны, проекты и память, все восемь разделов настроек, возможности IDE, история/работа/настройки независимой панели, окно IDE без проекта. В последнем ресурсы загружаются из разрешённой локальной директории webview с ограничивающим CSP.

Иллюстрации не перекрывают текст; на малой ширине декоративные заголовки скрываются вместе с резервным отступом. Настройка отключения рисунков сохранена.

## Инвентаризация мотивов

Общий контракт `src/design/leshy-motifs.css` используется тремя entrypoint: основным приложением, независимой панелью IDE и окном Лолы. Геометрические SVG-орнаменты остаются резкими при масштабировании; для трёх тем подготовлены ленты соответствующего цвета.

| Семейство | Применённое оформление |
| --- | --- |
| Оболочка, IDE/Chat, вкладки, списки проектов и разговоров | Рамки, углы, разделители и короткие плетёные ленты |
| Текстовые кнопки, поля, select, textarea | Небольшой тканый акцент в свободном месте; отдельная геометрия компактной строки состояния |
| Иконки, preview тем, checkbox и range | Угловой акцент, лента preview, отделка области подписи без закрытия самого контрола |
| Настройки, профили подключений, возможности, MCP, вложенные редакторы, копии | Общая поверхность, тонкая рамка, углы, розетки заголовков |
| Поиск, меню разговоров, голосовой popover, окна проектов/памяти/планов | Орнамент заголовка, рамки и ленты; сохранён доступ к действиям |
| Подтверждения, ошибки, несохранённые изменения, recovery, handoff | Общая отделка с сохранением сигнальных цветов; fixed-позиционирование handoff не изменено |
| История, Details, задачи, дочерние запуски, источники контекста | Рамки и украшенные заголовки/summary |
| Редактор, diff, код сообщений, таблицы, терминал | Мотивы на заголовках, вкладках и границах, без изображения поверх кода/вывода |
| Нативный Code-OSS | Titlebar/statusbar, заголовки панелей и терминала, quick input, меню, hover, уведомления, find/suggest, поля и кнопки |
| Независимая панель IDE | Навигация, все страницы, поля, composer, footer, ошибки и approvals |
| Отдельное окно Лолы | Лента пузыря, поля/действия, история и progress; фон окна остаётся прозрачным |

Область покрытия — элементы приложения и доступная оболочка Code-OSS. Системные диалоги Windows и произвольные сторонние extension webview не управляются этими стилями.

## Проверки и свидетельства

Все перечисленные сценарии завершились с `ok: true`, сборка и TypeScript прошли. Использованы изолированные профили и HTTP fixture, без загрузки тяжёлой модели.

| Проверка | Подтверждённый результат |
| --- | --- |
| `npm run build` | TypeScript, Vite, Electron |
| `LESHY_WINDOWS_MATRIX=1 node tests/electron/run.cjs leshy-themes.cjs` | 8 разделов × 3 темы, возможности IDE, проект, масштаб 125/200%, отключение рисунков, граница вкладок и statusbar; 0 запросов |
| `LESHY_POPOVER_REVIEW=1` + `leshy-themes.cjs` | Голосовой popover в трёх темах, рамка/лента и размещение внутри viewport; микрофон не включался |
| `studio-smoke.cjs`, полная матрица окон | Вложенные редакторы, меню, модальные окна, approvals, память, планы, восстановление; 23 fixture-запроса |
| `studio-layout.cjs` после последней правки | Геометрия основных панелей и компактного режима |
| `LESHY_PANEL_AUDIT=1` + `neutral-ide-integration.cjs` | 39 состояний: 240/320/420 px, 3 темы, 4 страницы и approvals; 2 fixture-запроса |
| `neutral-ide-integration.cjs` после обновления ресурсов | Настоящие Core/Code-OSS, diff/approval/undo/completion, сигнальные рамки, меню трёх тем; 6 fixture-запросов |
| `NEUTRAL_TEST_EMPTY_IDE=1` | Полноцветное изображение загрузилось, рисунок и кнопки внутри viewport; 0 запросов |
| `lola-desktop-smoke.cjs` | Прозрачность окна, лента в трёх темах, 1 Core и 1 fixture-запрос |

Проверены итоговые снимки. При захвате нативного меню учтена входная анимация: снимок после 400 ms и computed-style inventory подтверждают полную непрозрачность текста. Независимое ревью выявило риск перекрытия сигнальных рамок общим правилом и неверного containing block у notice; добавлены явные приоритеты состояний и локальная привязка углов.
