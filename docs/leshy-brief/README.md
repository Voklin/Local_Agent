# LESHY — комплект Markdown-промптов и дизайн-спецификаций

Проект: **LESHY / ЛЕШИЙ**, ребрендинг автономного AI coding agent на Electron + React + TypeScript + Python.

## Состав

1. [`01_LESHY_ASTRA_UI_REDESIGN.md`](01_LESHY_ASTRA_UI_REDESIGN.md) — главный промпт для **GPT Astra**: аудит репозитория, редизайн существующего UI, три темы, интеграция ресурсов без потери функциональности.
2. [`02_LESHY_ASSETS_GENERATION.md`](02_LESHY_ASSETS_GENERATION.md) — **отдельные генеративные промпты** для геометрических славянских орнаментов, фоновых иллюстраций и миниатюр тем + инструкция по подготовке ассетов.
3. [`03_LESHY_THEME_SYSTEM_GUIDE.md`](03_LESHY_THEME_SYSTEM_GUIDE.md) — руководство по **архитектуре тем и CSS-токенам** с примерами кода и чек-листом тестирования.
4. [`04_LESHY_LOGO_GENERATION.md`](04_LESHY_LOGO_GENERATION.md) — спецификация нового **минималистичного логотипа с ясно читаемыми оленьими рогами**, отдельные промпты и векторные требования.

## Как использовать

Передай GPT Astra четыре файла и приложи скриншоты текущего интерфейса, выбранный концепт LESHY, а также изображения-референсы орнаментов и старой книжной графики. Дай команду:

> Изучи все четыре Markdown-файла и репозиторий. `01` — основное техническое задание; `02` — создание ассетов; `03` — контракт тем; `04` — логотип. Сначала выполни аудит, затем реализуй изменения без регрессий. Если генератор изображений недоступен, честно отдели подготовленные промпты от реально созданных файлов; не блокируй весь редизайн из-за отсутствия генерации фонов.

Палитра **не фиксирована**: планируются «Лесная», «Парчовая» и «Сумеречная» темы. Визуальный мотив — современные технологии + славянские геометрические узоры и собственные лесные иллюстрации. Форма фирменного знака единая для всех тем.
