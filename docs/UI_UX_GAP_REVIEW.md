# Проверка пропущенных деталей прототипа Neutral

Дата: 28 октября 2026. Актуальная основа — визуальный прототип `prototypes/neutral-studio/index.html` по скриншоту пользователя. Эксперимент с существующей React-оболочкой отклонён. Python, агент, реальные проекты и внешние сервисы не подключаются до утверждения дизайна.

## Что изменено

История IDE перенесена из области файлов в раскрываемую панель «Разговоры» у чата агента, аналогично «Подробностям». Панели взаимоисключающие, сохраняют ширину агента и не отнимают место у редактора. Ctrl+K открывает поиск разговоров, Escape закрывает панель с возвратом фокуса. В Chat история остаётся слева. Лола по уточнению пользователя остаётся только отдельным всплывающим окном; встроенного режима в основной рабочей области нет.

Сохранены компоновка, графитовые поверхности, мятный акцент, верхний переключатель IDE/Chat, отображение пользовательского сообщения и выбор модели под полем запроса. ASCII не используется.

## Проверка и следующие границы

`npm run verify` открывает Electron и проверяет оба режима на 1280×720, 1440×900, 1920×1080 CSS px, включая изменение ширины панелей. Расширенный сценарий `verify-review.cjs` проверяет новые меню, историю, формы и решения. Результаты: `artifacts/verification.json` и `artifacts/review-verification.json`; новые снимки имеют префикс `review-`.

Геометрические проверки и локальные сценарии не подтверждают сохранённую функциональность основного приложения. Полный Markdown, промышленный редактор, реальные инструменты / подтверждения / recovery, модель, голос и системные интеграции остаются за границей этого этапа. Их следует подключать после утверждения, сохраняя эту визуальную основу и существующие обработчики.
