основной/отдельной модели, передаче задач, каталоге озвучки и Telegram help.

Лола получила розовые акценты, мягкие поверхности, округлые карточки, приветствие
и декоративное сердечко у персонажа. Атлас и работающие состояния сохранены.
Компонент `MiyaAvatar.tsx` переименован в `LolaAvatar.tsx` вместе с экспортами.
Физические файлы ONNX и идентификатор `miya-anime-ru` не переименованы: это
контракт совместимости существующего сервера, хеша модели и пользовательской
установки. Аналогично сохранены ключи localStorage голосового ввода и CSS-классы
`miya-*`; отображаемое имя всегда Лола.

## Настраиваемый интерфейс

Общие настройки открываются значком в верхней панели. Вкладка «Оформление»
управляет тёмной/светлой темой, лавандовым/небесным/мятным акцентом, свободной/
компактной плотностью, боковой панелью, журналом IDE и строкой состояния.
Тема применяется и к окнам настроек, подтверждениям и редактору. У Лолы собственный
розовый акцент в обеих темах. По умолчанию история видна, журнал и нижняя строка
скрыты; доступ к настройкам остаётся в шапке даже при скрытой боковой панели.

Настройки хранятся под `localagent.appearance.v1` в localStorage профиля Electron,
без данных проекта и API-ключей. Применяются сразу, независимо от кнопки сохранения
модели; сброс оформления возвращает все шесть параметров к стандартным значениям.

| Функция AppearanceSettings.tsx | Назначение |
| --- | --- |
| readAppearance | Проверяет whitelist значений и типы флагов; повреждённый JSON возвращает безопасные defaults. |
| saveAppearance | Сохраняет локальный JSON и отправляет appearance-changed. |
| useAppearance | Подписывает компонент на локальное событие и storage; удаляет слушателей при unmount. |
| AppearanceSettings | Показывает форму; update объединяет частичное изменение с текущими настройками и сообщает об ошибке записи. |

App устанавливает `data-theme`, `data-accent`, `data-density` и классы видимости на
корневом элементе. Компоненты не подменяют файлы проекта и настройки inference.

## Настройки моделей и общая форма

ModelSettings разделён на «Подключение», «Ответы модели», «Локальный запуск»,
«Инструменты» и «Оформление». Draft модели сохраняется при переходе между
вкладками. Сервер, ID, ключ, обнаружение и пробный запрос остаются в подключении.
Стандартные пресеты «Точный код», «Разговор», «Короткий ответ» меняют только
temperature/top_p/max_tokens в черновике; URL, модель и лимиты задачи сохраняются.
Для применения параметров модели нужна кнопка «Сохранить настройки».

`GenerationFields.tsx` содержит общий `GenerationSettings`, значения по умолчанию,
семь описателей диапазонов/подсказок и компонент числовых полей. Его используют
ModelSettings и CompanionSettings. Убрана дублирующая разметка генерации отдельной
модели; её поля также блокируются на время задачи. Серверная валидация сохраняется.
Ошибки числовых параметров переключают окно на вкладку с этими параметрами.
Для Chat и IDE сохраняется одна основная конфигурация; у Лолы — отдельный профиль.

Настройки Лолы остаются по отдельной кнопке в режиме ассистента. Нативный dialog
открывается/закрывается непосредственно через ref, без второго React-состояния
open: устранена гонка отложенного события close при быстром повторном открытии.
Escape и крестик закрывают окно, фокус возвращается к кнопке.

## Структура CSS и доказанная очистка

`style.css` теперь только задаёт порядок импорта:

1. `styles/base.css`: базовые элементы, IDE, карточки и подтверждения.
2. `styles/workspaces.css`: расположение режимов и общие окна.
3. `styles/companion.css`: персонаж, состояния и настройки голоса.
4. `styles/modern.css`: актуальные токены и оформление, темы и пользовательские переключатели.

При переносе сохранён порядок существующего каскада. Поиск по TS/TSX подтвердил
отсутствие использования `maid-concept`, `companion-orbit`, `concept-caption`,
`voice-capabilities`, `maid-mouth` и старого элемента version. Удалено 21 правило/
keyframes, относящееся к этим остаткам SVG и старой шапки. Из VoicePanel удалён
неиспользуемый экспорт VoiceProfile. Удалены локальные разовые скрипты
`.test-data/refactor-voice-settings.py`, `update-voice-smoke.py`,
`bump-serena-version.py`: ссылок в tracked файлах нет, они не нужны для сборки.
Машиночитаемый перечень CSS-удалений сохранён в `.test-data/lola-css-cleanup.json`.

Аудит не выявил других доказанно лишних tracked файлов, которые можно безопасно
удалить: `main.py`, `agent/ui.py`, `run.bat` обслуживают старый Qt запуск;
`design_reference` — документированный учебный архив, используемый генератором
справочников; `tools/tts/training` нужен для воспроизводимости Serena. Они сохранены.
Модели, записи, checkpoints, установщики, пользовательские настройки и виртуальные
окружения не очищались. Границы чтения/записи, diff-подтверждения и Telegram owner
не ослаблялись. Большая часть Python ядра сохраняет прежние обязанности: это аудит
и целевой рефакторинг сквозных UI-контрактов, а не переписывание каждого модуля.
