# LocalAgent 6.1.0 — Chat, IDE и отдельная Мия

- История Мии отделена от Chat; кнопки М/C позволяют перенести старые разговоры без удаления сообщений.
- Отдельные модель/API, характер, параметры генерации и сохраняемые настройки голоса Мии. Сложные задачи передаются основной модели Chat/IDE, итог возвращается в историю Мии.
- Микрофон по нажатию: до 60 секунд, WAV 16 kHz, отменяемая транскрипция через настроенный whisper.cpp или совместимый STT API. Текст можно проверить до отправки.
- JSON tool calling для моделей без native tools API, включая проверенный Qwen 2.5 Coder. В настройках выберите JSON. Сохраняются sandbox, diff и подтверждение записи.
- KV-кеш K/V f16/q8_0/q4_0, CPU threads, один слот и сохранение параметров встроенного GGUF-сервера.
- Включаемые PC tools: скриншот, браузерный поиск, read-only чтение папок только по путям из исходного сообщения. Скриншоты показываются локально; автоматический VLM-анализ и мышь/клавиатура этим обновлением не добавлены.
- Telegram: token + ваш user ID в настройках, команды состояния/Stop/Chat/IDE/Мия и подтверждения diff. Посторонние и группы игнорируются. Токен можно сохранить через системное защищённое хранилище.

Windows 10/11 x64. Python, Electron/Node.js, llama.cpp CPU и официальный офлайн-установщик Visual C++ включены. Веса GGUF, STT-сервер/модель и дополнительные Windows-голоса настраиваются отдельно. Запись микрофона без STT-сервера не превращается в распознавание. Telegram нужно подключить своим токеном и user ID; приложение и ПК должны работать.

Предварительная сборка без подписи издателя. Контрольная сумма — SHA256SUMS.txt. Проверки исходников, frozen Core и packaged exe выполняются перед публикацией.
