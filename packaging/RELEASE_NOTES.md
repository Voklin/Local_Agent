# LocalAgent 6.2.0 — нейроозвучка и активация Мии голосом

- Qwen3-TTS VoiceDesign с русским языком и редактируемым профилем «Мия · аниме»: тембр и манера речи задаются описанием.
- Отменяемый синтез по HTTP, проверка PCM WAV, воспроизведение с темпом/громкостью и Stop. Голоса Windows также доступны.
- Настраиваемая фраза «Привет, Мия» во всех режимах. Явная кнопка включает микрофон; команда заполняет поле или отправляется по отдельной настройке.
- Прослушивание на паузе во время задачи, ручной записи и собственной озвучки. После перезапуска микрофон выключен.
- В установщике есть папка TTS с PowerShell-скриптом установки/запуска и инструкцией, доступная из настроек Мии.

Для нейроозвучки отдельно нужен Python 3.12. Скрипт устанавливает отдельную среду CPU PyTorch/qwen-tts и загружает официальную модель (несколько ГБ). На CPU синтез может быть медленным. Качество аниме-стиля и постоянство тембра зависят от модели и описания; настоящее прослушивание модели в текущем сеансе не выполнялось. Протокол и GUI проверены с синтетическим аудио.

Для фразы активации нужен работающий STT-сервер, например whisper.cpp. Фрагменты с обнаруженной речью передаются в настроенный STT URL. Стандартные TTS/STT адреса — localhost.

Основной Windows x64 установщик включает Electron/Node.js, frozen Python Core, llama.cpp CPU и офлайн-установщик Visual C++. Веса GGUF и speech-моделей настраиваются отдельно. Предварительная сборка без подписи издателя; checksum — SHA256SUMS.txt.
