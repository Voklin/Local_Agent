# LocalAgent 6.7.0 — последовательные роли IDE

- Дирижёр планирует, автор передаёт полный код, сборщик создаёт файлы через diff approval, проверяющий читает результат и возвращает pass/revise.
- Полный цикл или отдельная роль, назначение моделей, локальные передачи, bounded исправления и resume без повторения завершённых этапов.
- LM Studio 0.4+/Ollama: последовательная загрузка и выгрузка назначенных моделей. Внешний API — без управления памятью.
- Сохранены дизайн 6.6, sandbox, diff/revision проверки, отдельные Chat и Лола. Проверка включает чтение и AST/JSON, не автоматический запуск произвольных тестов проекта.
- Умное сжатие истории без дополнительных LLM запросов: ограничения, факты tools и релевантные фрагменты; полный текущий код сохраняется, статистика видна в плане.
- Лола: поиск/открытие музыки, локальный аудиоплеер, заметки, таймеры с уведомлениями, часы и калькулятор. Музыкальная страница может требовать Play; таймеры работают при открытом приложении.

## Лола и оформление 6.6

- Мия стала Лолой: интерфейс, подсказки модели, озвучка и Telegram. Стандартная фраза — «Привет, Лола»; пользовательские фразы и история сохраняются.
- Более мягкое оформление Лолы; минималистичные Chat/IDE с выбором темы, акцента, плотности и панелей.
- Настройки разделены по вкладкам; добавлены пресеты ответов и общая форма генерации для основной модели и Лолы.
- CSS разделён по слоям, удалены старые правила SVG-аватара и временные скрипты. Подробный аудит — docs/33-lola-refactor-and-appearance.md.

## Голосовой ввод 6.5

- Настройки Мии вынесены в отдельное окно по кнопке: на главном экране остаётся разговор.
- Запись завершается по паузе; лишняя тишина обрезается до отправки STT. Добавлены подавление шума и отмена голосового ввода.
- Можно включить отправку распознанного запроса сразу; по умолчанию текст доступен для проверки. Скорость модели STT зависит от оборудования.

## Serena и персонаж

- Озвучка «Мия · Serena» на CPU: запуск и проверка локального Piper из интерфейса, проба голоса, скорость и громкость в процентах.
- Анимированный персонаж по выбранному изображению: ожидание, слушание, размышление, работа, речь, успех и ошибка. Движение можно отключить.
- Windows и внешний HTTP/Qwen остаются доступными. Существующий профиль не переключается без выбора пользователя.
- Эта локальная сборка использует уже установленные Piper и обученную Serena. На другом ПК компоненты и ONNX/JSON устанавливаются отдельно; веса и датасет в установщик не включены.

## Возможности предыдущих версий

- Qwen3-TTS VoiceDesign с русским языком и редактируемым профилем «Мия · аниме»: тембр и манера речи задаются описанием.
- Отменяемый синтез по HTTP, проверка PCM WAV, воспроизведение с темпом/громкостью и Stop. Голоса Windows также доступны.
- Настраиваемая фраза «Привет, Мия» во всех режимах. Явная кнопка включает микрофон; команда заполняет поле или отправляется по отдельной настройке.
- Прослушивание на паузе во время задачи, ручной записи и собственной озвучки. После перезапуска микрофон выключен.
- В установщике есть папка TTS с PowerShell-скриптом установки/запуска и инструкцией, доступная из настроек Мии.

Для нейроозвучки отдельно нужен Python 3.12. Скрипт устанавливает отдельную среду CPU PyTorch/qwen-tts и загружает официальную модель (несколько ГБ). На CPU синтез может быть медленным. Качество аниме-стиля и постоянство тембра зависят от модели и описания; настоящее прослушивание модели в текущем сеансе не выполнялось. Протокол и GUI проверены с синтетическим аудио.

Для фразы активации нужен работающий STT-сервер, например whisper.cpp. Фрагменты с обнаруженной речью передаются в настроенный STT URL. Стандартные TTS/STT адреса — localhost.

Основной Windows x64 установщик включает Electron/Node.js, frozen Python Core, llama.cpp CPU и офлайн-установщик Visual C++. Веса GGUF и speech-моделей настраиваются отдельно. Предварительная сборка без подписи издателя; checksum — SHA256SUMS.txt.
