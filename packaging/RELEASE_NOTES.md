# LocalAgent 6.0.1 для Windows 10/11 x64

Запустите `LocalAgent-6.0.1-setup-x64.exe`. Установка Python, Node.js, Electron и llama.cpp вручную не нужна: они входят в пакет. Официальный Microsoft Visual C++ Runtime 14.51 x64 устанавливается офлайн при отсутствии подходящей или более новой версии; Windows может запросить права администратора.

В настройках GGUF выберите файл модели: CPU-сервер уже включён и выбирается автоматически. Для GPU можно указать другой совместимый llama-server. Также поддерживается подключение к запущенному LM Studio через его API.

Модели GGUF не входят в установщик из-за размера и разных требований к памяти. Выберите и скачайте подходящую модель отдельно. Для работы с локальным GGUF после установки интернет не требуется.

Три режима: Chat, IDE и голосовой компаньон. Озвучивание использует установленные в Windows голоса System.Speech. Распознавание речи с микрофона пока не реализовано; кнопка микрофона отключена.

Сборка предварительная и не подписана сертификатом издателя. Контрольная сумма установщика опубликована в `SHA256SUMS.txt`.
