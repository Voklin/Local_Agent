# Локальный аниме-голос Мии

Используется официальная модель
[Qwen3-TTS-12Hz-1.7B-VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)
(Apache-2.0). Она поддерживает русский и проектирование голоса по описанию.
Профиль Мии задаёт молодой взрослый женский голос с выразительной аниме-интонацией;
описание можно изменить. Это синтез по инструкции, качество и постоянство тембра
между фразами нужно оценивать прослушиванием. Записи актёров не требуются.

## Установка и запуск Windows

### Piper: лёгкая CPU озвучка

Пробный русский голос — [Irina medium](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/irina/medium).
Скачайте `ru_RU-irina-medium.onnx` и `ru_RU-irina-medium.onnx.json` в
`%LOCALAPPDATA%/LocalCodingAgent/speech/piper/`. Затем запустите:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-piper.ps1
```

Нужен Python 3.12 (либо `-PythonPath`); скрипт создаёт отдельную среду
`%LOCALAPPDATA%/LocalCodingAgent/piper-runtime` и устанавливает `piper-tts==1.8.0`.
Для другого уже скачанного голоса укажите `-ModelPath` с путём к ONNX и его JSON.
Движок использует ONNX Runtime CPUExecutionProvider, PyTorch/CUDA не требуются.
Модель Irina занимает 63 201 294 байта; SHA256:
`8ff38212d23da300bbe3705c645e6e5b9475f0bfde01558eb17813e22acaaaaa`.

Адрес прежний: `http://127.0.0.1:9080/v1/audio/speech`, готовность — `/health`.
В существующей версии приложения можно оставить пункт Qwen3-TTS: он обращается
к этому совместимому HTTP API, а фактический движок определяется запущенным сервером.
Описание характера/тембра не меняет готовый голос Irina. Это русский женский
голос без специального обучения аниме-интонации; оцените запись на слух.
Приложение получает PCM16 mono 22050 Гц. Stop/deadline проверяются между
предложениями; текущий вызов ONNX нельзя прервать посередине.

На этом ПК прежний `speech/Start-TTS.cmd` теперь запускает Piper; резерв запуска
Ono_Anna — `speech/Start-TTS-Qwen-OnoAnna.ps1`. Для возврата остановите Piper и
запустите резервный скрипт через PowerShell. Одновременно порт может занимать один сервер.
Piper/Irina не встраивались в установщик и не публиковались. Piper распространяется
по GPL-3.0; карточка Irina указывает `Dataset License: Unknown`, поэтому нельзя
приписывать голосу лицензию Apache/MIT. См. [Piper](https://github.com/OHF-Voice/piper1-gpl)
и [карточку голоса](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/irina/medium/MODEL_CARD).

### Проба лёгкой модели с готовым голосом

Для Qwen3-TTS 0.6B CustomVoice с готовым голосом Ono_Anna:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-tts.ps1 -Device cuda -Model custom-0.6b -Speaker Ono_Anna
```

Официальная модель: [Qwen3-TTS-12Hz-0.6B-CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice).
Она загружается отдельно от VoiceDesign; файлы занимают около 2,5 ГБ на диске.
Это размер файлов, а не обещанный расход RAM/VRAM. Перед CUDA-загрузкой проверяется
минимум 3 ГиБ свободной VRAM; проверка не резервирует память для последующих запросов.
Ono_Anna — готовый игривый женский голос с родным японским языком. Синтез настроен
на Russian; произношение и тембр на русском следует оценить прослушиванием.
Можно выбрать `-Speaker Serena`, `Vivian` или другие поддерживаемые пресеты.
В этом режиме описание тембра из профиля не используется: голос задаёт `-Speaker`.
URL и выбор движка в приложении остаются прежними; `/health` показывает модель и speaker.
Параметры передаются из PowerShell в Python `--model`/`--speaker`; генерация вызывает
`generate_custom_voice`. Без `-Model` по-прежнему запускается VoiceDesign 1.7B.
Возврат: остановите сервер и запустите тот же скрипт с `-Model voicedesign-1.7b`.
Один порт 9080 может обслуживать только один экземпляр TTS одновременно.

### Обычная установка

Требуется Python 3.12 с `py` launcher. Откройте PowerShell в этой папке:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-tts.ps1
```

Первый запуск создаёт отдельную среду в
`%LOCALAPPDATA%/LocalCodingAgent/tts-runtime`, устанавливает CPU PyTorch и qwen-tts,
затем загружает официальную модель с Hugging Face (несколько ГБ). Нужны свободное
место, RAM для модели и интернет при первой установке. Дождитесь `Ready`.
Окно нужно оставить открытым. Ctrl+C останавливает сервер.

Если Python 3.12 установлен без регистрации в `py`, укажите его явно:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-tts.ps1 -PythonPath "C:\path\to\python312\python.exe"
```

Параметр `-InstallOnly` устанавливает зависимости без загрузки весов и запуска
модели. Повторный запуск восстанавливает отсутствующий PyTorch, в том числе после
прерванной установки. Уже установленный CUDA PyTorch сохраняется.
Параметр `-LowMemory` выбирает BF16 вместо FP32 для весов на CPU и сокращает
память весов основной модели примерно вдвое. Скорость зависит от поддержки BF16
процессором; формат не меняет выбранное устройство и не включает GPU.

В Ассистенте откройте настройки характера/модели/распознавания:

- Движок озвучки: **Qwen3-TTS · Мия, аниме на русском**.
- TTS URL: `http://127.0.0.1:9080/v1/audio/speech`.
- Измените описание тембра при необходимости и сохраните профиль.
- Нажмите «Озвучить текст» или включите автоматическую озвучку.

Сервер слушает только localhost, принимает JSON без CORS и одну генерацию
одновременно. Проверка готовности: `http://127.0.0.1:9080/health`.
Загрузчик сначала получает снимок файлов официальной модели, затем передаёт
локальную папку в Qwen3-TTS. Это позволяет запускать уже скачанную модель при
`HF_HUB_OFFLINE=1` без повторного обращения токенизатора к API Hugging Face.
На CPU используйте короткие фразы: синтез может быть заметно медленнее речи.
Для NVIDIA запустите `start-tts.ps1 -Device cuda`. Скрипт при необходимости
установит согласованные `torch/torchaudio 2.11.0+cu128` из официального CUDA 12.8
индекса PyTorch. Отдельный CUDA Toolkit не нужен. По умолчанию CPU остаётся
доступным; ключ `-Device auto` выбирает GPU только при уже работающем CUDA PyTorch.
Для GPU используются BF16 и SDPA, проверяется пробная CUDA-операция и минимум
6 ГиБ свободной VRAM до загрузки модели. При нехватке памяти выгрузите большую
LLM или используйте `-Device cpu -LowMemory`. Не загружайте большую модель
LM Studio после старта TTS, если она не помещается в оставшуюся видеопамять.

Проверка на RTX 5070: «Привет! Я Мия.» дала 1,76 секунды WAV за 20,39 секунды
первого CUDA-запроса и 5,55 секунды следующего, против 85,03 секунды CPU BF16.
Это примерно 15-кратное ускорение после прогрева, а не гарантированная скорость
для любых текстов. Фраза распознана STT обратно; воспроизведение не запускалось.
После прогрева общая занятая VRAM составляла около 6,2 ГБ, включая другие приложения.
Рекомендации runtime: [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS),
[официальные CUDA-сборки PyTorch](https://pytorch.org/get-started/previous-versions/).

Приложение принимает только PCM16 mono WAV до 120 секунд/15 МБ. Stop отменяет
HTTP и воспроизведение. Текст передаётся в выбранный TTS URL;
стандартный адрес остаётся на вашем ПК.
На каждом шаге talker сервер проверяет отключение клиента и срок 150 секунд.
Отмена/таймаут HTTP останавливает генерацию при следующем forward; текущую
операцию PyTorch прервать посередине нельзя. Hook и слот освобождаются в finally.
HTTP 429 означает занятый слот, 504 — превышение времени; подробности типа ошибки
пишутся в журнал без текста и описания голоса.
Полный PyTorch и веса не встраиваются в основной установщик LocalAgent.

## Если появляется ConnectError

Это ошибка соединения: приложение не смогло подключиться к указанному серверу.
Выбор движка и сохранение URL сами сервер не запускают. Для TTS дождитесь `Ready`
и ответа `/health`; загрузка весов ещё не означает готовность HTTP-сервера.
Для STT отдельно запустите `whisper-server` с многоязычной моделью (без `.en`),
адрес приложения должен включать `/inference`. Инструкция: [STT](../../docs/26-miya-model-and-stt.md).
LM Studio обслуживает чат-модель и не заменяет эти два голосовых сервера.
После перезагрузки ПК серверы нужно запустить снова. Не увеличивайте параллелизм
и не загружайте нейроозвучку одновременно с большой LLM без запаса системной памяти.

## Активация голосом

Нужен работающий STT (например whisper.cpp); TTS не распознаёт микрофон.
Фраза по умолчанию — «Привет, Мия». Сохраните профиль и нажмите «Активация голосом»
вверху приложения. Укажите фразу и команду подряд либо произнесите команду следующим
фрагментом в течение 15 секунд. По умолчанию текст можно проверить перед отправкой;
для работы без кнопки включите «Отправлять голосовую команду сразу после фразы».
Прослушивание приостанавливается на время задачи, записи вручную и озвучки.
После перезапуска приложения нужно включить его снова.
