# Локальный аниме-голос Мии

Используется официальная модель
[Qwen3-TTS-12Hz-1.7B-VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)
(Apache-2.0). Она поддерживает русский и проектирование голоса по описанию.
Профиль Мии задаёт молодой взрослый женский голос с выразительной аниме-интонацией;
описание можно изменить. Это синтез по инструкции, качество и постоянство тембра
между фразами нужно оценивать прослушиванием. Записи актёров не требуются.

## Установка и запуск Windows

Требуется Python 3.12 с `py` launcher. Откройте PowerShell в этой папке:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-tts.ps1
```

Первый запуск создаёт отдельную среду в
`%LOCALAPPDATA%/LocalCodingAgent/tts-runtime`, устанавливает CPU PyTorch и qwen-tts,
затем загружает официальную модель с Hugging Face (несколько ГБ). Нужны свободное
место, RAM для модели и интернет при первой установке. Дождитесь `Ready`.
Окно нужно оставить открытым. Ctrl+C останавливает сервер.

В Ассистенте откройте настройки характера/модели/распознавания:

- Движок озвучки: **Qwen3-TTS · Мия, аниме на русском**.
- TTS URL: `http://127.0.0.1:9080/v1/audio/speech`.
- Измените описание тембра при необходимости и сохраните профиль.
- Нажмите «Озвучить текст» или включите автоматическую озвучку.

Сервер слушает только localhost, принимает JSON без CORS и одну генерацию
одновременно. Проверка готовности: `http://127.0.0.1:9080/health`.
На CPU используйте короткие фразы: синтез может быть заметно медленнее речи.
Для NVIDIA можно установить совместимый CUDA PyTorch в ту же среду и запустить
`start-tts.ps1 -Device cuda`; скрипт по умолчанию устанавливает CPU-вариант.

Приложение принимает только PCM16 mono WAV до 120 секунд/15 МБ. Stop отменяет
HTTP и воспроизведение; сервер может завершать уже начатую генерацию до освобождения
слота. Текст передаётся в выбранный TTS URL; стандартный адрес остаётся на вашем ПК.
Полный PyTorch и веса не встраиваются в основной установщик LocalAgent.

## Активация голосом

Нужен работающий STT (например whisper.cpp); TTS не распознаёт микрофон.
Фраза по умолчанию — «Привет, Мия». Сохраните профиль и нажмите «Активация голосом»
вверху приложения. Укажите фразу и команду подряд либо произнесите команду следующим
фрагментом в течение 15 секунд. По умолчанию текст можно проверить перед отправкой;
для работы без кнопки включите «Отправлять голосовую команду сразу после фразы».
Прослушивание приостанавливается на время задачи, записи вручную и озвучки.
После перезапуска приложения нужно включить его снова.
