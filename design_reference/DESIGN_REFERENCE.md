# Agent Studio — UI design reference

Исходный дизайн сохранён из загруженного `agent_studio.py`. Этот файл — эталон визуальной структуры и не используется как runtime-ядро.

## Перенесено в Local Coding Agent
- тёмная IDE-палитра и синий акцент;
- вертикальная Activity Bar и боковая навигация;
- верхняя панель проекта, модели и статуса;
- центральная рабочая область;
- нижняя панель чата и вывода;
- вкладки предпросмотра файлов (только чтение).

## Намеренно не переносилось из эталона
- реализация агента и запуска задач;
- альтернативная файловая/командная система разрешений;
- любые прямые операции записи из UI.

В проекте остаются исходные `AgentWorker`, `security.resolve_allowed_path`, подтверждение записи и хранилища чатов/памяти. Файловые вкладки read-only, поэтому новый UI не создаёт обхода подтверждения записи.
