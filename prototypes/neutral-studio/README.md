# Neutral — визуальный прототип

Сейчас оцениваем только дизайн на основе скриншота пользователя: IDE/Chat в верхней панели, файлы слева, редактор в центре, чат агента справа. Исходники этой дизайн-основы: `index.html`, `app.js`, `app.css`; дополнительные демо-состояния — `review-ui.js` и `review-ui.css`.

## Запуск

Из `LocalAgent/prototypes/neutral-studio`:

```powershell
npm start
```

Нужен Electron из зависимостей корня LocalAgent. Python и агент не запускаются; сетевые запросы запрещены. Сообщения, инструменты, файлы, настройки и окно Лолы демонстрируют взаимодействия на локальных примерах. Они не выдают себя за работу настоящих сервисов.

`npm run verify` проверяет демонстрационные взаимодействия и сохраняет снимки IDE/Chat в трёх размерах в `artifacts/`. Ширина боковых панелей изменяется мышью и клавиатурой; сохраняется локально.

## Граница работ

Подключение функций и изменение основного приложения выполняются только после утверждения дизайна. Неудачный эксперимент с существующей оболочкой сохранён в `functional/` и `functional-*.cjs` для истории; он не запускается через `npm start` и не является текущим прототипом.

История IDE открывается кнопкой «Разговоры» у чата агента, Chat сохраняет историю слева. Лола остаётся только отдельным всплывающим окном. Покрытие пропущенных деталей и ограничения: `docs/UI_UX_GAP_REVIEW.md` в корне LocalAgent.
